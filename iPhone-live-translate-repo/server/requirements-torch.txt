# Install this FIRST, before requirements.txt.
#
# Why it's a separate file: silero-vad depends on BOTH torch and torchaudio.
# If you install requirements.txt first, pip satisfies those from the default
# PyPI index. On Windows that means a CPU-only torch, and — worse — a
# torchaudio built against a different torch than yours, which fails at import
# with "WinError 127: The specified procedure could not be found".
#
#     pip install -r requirements-torch.txt
#     pip install -r requirements.txt
#
# ---------------------------------------------------------------------------
# torch and torchaudio MUST be the same version, from the SAME index.
# Mismatching them is what produces WinError 127.
#
# Set these to match your working project. Run there:
#
#     python check_gpu.py
#
# and paste the lines it prints in place of the ones below.
#
# Index options:
#   cu130  CUDA 13.0 — current default, Turing (RTX 20xx) and newer
#   cu126  CUDA 12.6 — for older drivers, and Maxwell/Pascal/Volta cards
#   cu124  older torch releases only; dropped from the current build matrix
#   cpu    explicit CPU-only, if you ever want it
# ---------------------------------------------------------------------------

--index-url https://download.pytorch.org/whl/cu126

torch==2.9.1
torchaudio==2.9.1
